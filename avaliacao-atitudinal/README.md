# Sistema de Avaliação Atitudinal

Protótipo acadêmico desenvolvido em HTML e CSS para simular um sistema de acompanhamento atitudinal no ensino básico.

## Perfis disponíveis

- Professor
- Coordenação
- Estudante
- Responsável

## Como abrir

Abra o arquivo `index.html` no navegador. A partir dele é possível acessar os quatro perfis e navegar pelas telas do protótipo.

## Tecnologias

- HTML5
- CSS3

O projeto não utiliza JavaScript, banco de dados ou backend. Os dados apresentados são apenas exemplos para demonstrar a navegação.

## Organização

- `index.html`: tela inicial
- `professor/`: telas do professor
- `coordenacao/`: telas da coordenação
- `estudante/`: telas do estudante
- `responsavel/`: telas do responsável
- `css/styles.css`: estilos de todas as páginas
