# Avaliação Atitudinal

Sistema web de **avaliação atitudinal de alunos** para escolas. A plataforma permite registrar, acompanhar e consultar o comportamento e a postura dos estudantes (participação, responsabilidade, respeito, colaboração, entre outros), apoiando professores e a coordenação pedagógica na tomada de decisões.

> 🚧 **Status:** em desenvolvimento. Por enquanto, o projeto é *full stack* (front-end e back-end).

## Getting Started

1. **Clone o projeto**: `git clone https://github.com/FilipeLSantos/avaliacao-atidudinal-web.git`
2. **Instale as dependências**: `npm install` (ou `yarn`)
3. **Variáveis de ambiente**: copie `.env.example` para um novo `.env`
4. **Inicie o desenvolvimento**: `npm run dev` (front-end) & `npm run start:dev` (API)

> ⚠️ Os comandos acima são o padrão e podem mudar conforme a estrutura do projeto evoluir.
